# JWIT Website

JWIT is a responsive multi-page community website for Jamshedpur Women in Technology. It helps members discover events, resources, mentorship, sponsors, and ways to participate in the local technology community.

## Features

- Home, core team, membership, events, sponsors, resources, gallery, and contact pages
- React Router navigation with dropdown menus and active links
- Light and dark themes with responsive drawer navigation
- Event details, gallery lightbox, resource sections, and accessible forms
- Local image assets, responsive layout, icon-only social and support footer links

## Tech stack

React, Vite, React Router, styled-components, Material UI, react-icons, and local image assets.

## Run locally

```bash
npm install
npm run dev
```

Build and deploy:

```bash
npm run lint
npm run build
npm run deploy
```

## Future direction

The project can grow with richer event registration, community updates, sponsor dashboards, and more local learning resources.
